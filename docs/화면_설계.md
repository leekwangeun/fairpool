# 화면 설계 (차량 화면)

차량탈출 : AI 멀티버스의 차 앱 화면입니다. 피그마 시안과 Compose 코드가 모두 이 문서를 따릅니다.

- 피그마 시안: https://www.figma.com/design/SeNCOGTRTxa1APcUJz6GKC
- 대상: 유아와 초등 저학년 아이, 그리고 운전석의 보호자
- 큰 틀: Pleos 에뮬레이터 기준 차량 화면(밝은 바탕, 흰 둥근 카드, 헤더 오른쪽 상태 알약, 2단 또는 3단 배치)

## 1. 원칙

| 원칙 | 화면에서 지키는 방법 |
|---|---|
| 아이가 바로 알아봄 | 캐릭터 얼굴, 테마별 큰 색 면, 별로 보는 진행, 숫자 칸, 짧은 문장 |
| 보호자는 한눈에 확인 | 헤더 오른쪽에 늘 안전 상태 알약, 보호자 할 일과 아이 할 일을 다른 색 카드로 나눔 |
| 차 안에서 누르기 쉬움 | 주 버튼 높이 104 이상(말하기 112), 칩과 키는 높이 84 이상, 글자 22 이상 |
| 언제든 멈춤 | 플레이 중 헤더에 빨간 "비상 전체 해제" 버튼 |
| 운전 중에는 쓰지 않음 | 기어가 P가 아니면 게임을 끝내고 원상 복구(E3) |

## 3. 화면 목록

| 번호 | 이름 | 언제 |
|---|---|---|
| E0 | 홈 | 앱을 켜면 |
| E1 | 안전 확인 | 테마를 고르면 |
| E2 | 플레이 | 시작을 누르면. 가운데 그림이 기믹마다 바뀜 (7종) |
| E3 | 일시정지 | 문 열림, 벨트 풀림, 아이가 자리를 비움, 주행 전환 |
| E4 | 탈출 성공 | 마지막 암호를 맞히면 |
| E5 | 설정 | 홈의 설정 버튼 |
| E6 | NPC 대화 | 플레이 화면의 말하기 버튼 |

## 4. E0 홈

- 헤더: 파란 로고 타일(별), "차량탈출 : AI 멀티버스", 차량 상황 칩 3개(장소, 날씨, 배터리), 상태 알약 "주차 중", 설정 버튼.
- 인사: 캐릭터 얼굴과 "오늘은 어떤 모험을 할까?"
- 테마 카드 4장을 가로로. 지금 상황에 맞는 카드 하나는 굵은 테두리와 색 채운 추천 칩(예: 비 오는 밤이면 테마 3 "비 오는 밤 특별편").
- 아래 2장: "글로브박스에 보물을 넣어요"(연한 주황 카드, 선물 그림), "우리 크루"(1열 기관장 파란 태그, 2열 탐정 초록 태그와 아이 자리 칩).

## 5. E1 안전 확인

- 헤더: 돌아가기, "테마 1 / 보물 잠수함 준비 중", 상태 알약(잠그는 중이면 파란 점, 끝나면 초록 점 "안전 잠금 완료").
- 왼쪽 카드: 초록 방패와 "출발 전 안전 확인". 6줄: 기어 P, 보호자와 아이 착석, 아이 안전벨트, 문 닫힘과 잠금, 창문 닫힘과 잠금, 글로브박스 잠금. 줄마다 점과 오른쪽 상태(통과, 진행 중, 확인 필요, 건너뜀).
- 오른쪽 카드(테마 연한 색): 캐릭터와 이름, 말풍선에 에피소드 제목과 시작 대사, 상황 칩, "만든 곳" 한 줄, 맨 아래 테마색 "방탈출 시작!" 버튼(높이 120). 모두 통과해야 켜짐.

## 6. E2 플레이

세 칸: 왼쪽 캐릭터 카드 430, 가운데 기믹 카드, 오른쪽 크루 칸 420. 맨 아래에 4D 연출 칩 줄.

- 헤더: 테마 번호 타일, 테마 이름과 "2 / 6 단계 김 서린 해류 암호", 별 6개, 경과 시간 칩, 상태 알약, 비상 전체 해제.
- 왼쪽: 캐릭터(테마색), 이름, 말풍선 대사, 아래에 "모은 숫자" 칸 5개(찾은 숫자는 테마색, 아직은 점선 물음표).
- 오른쪽: "1열 기관장 (보호자)" 연한 파랑 카드, "2열 탐정 (아이)" 연한 초록 카드, 힌트 카드(열었을 때), 아래에 말하기(112)와 힌트 보기 버튼.

| 기믹 | 가운데 그림 | 통과 조건 |
|---|---|---|
| 성애 제거 | 앞 유리 그림, 숫자 위에 김. 켜면 김이 걷힘 | 앞 유리 성애 제거, 최대 성애 제거, 사이드미러 열선 중 하나 |
| 빛의 조각 | 위에서 본 차와 창문 4개. 밝은 창은 해, 나머지는 달 | 아이가 말한 창을 누르거나 말하기 |
| 공기 정화 | 먼지 막기 게이지, 내기 순환과 공기청정 스위치 타일 | 둘 다 켜짐 |
| 손전등 신호 | 빛나는 전구, 번호 원 3개 | 아이 좌석 독서등을 목표 횟수만큼 켬 |
| 금고 다이얼 | 다이얼과 초록 목표 칸, 아래에 단계 칩(핸들, 브레이크, 깜빡이) | 목표 각도 ±12도에서 브레이크, 그 뒤 깜빡이 목표 횟수 |
| 온도 암호 | 쪽지("열여덟 도 반"), 온도계와 지금 온도 | 공조 온도가 목표와 같음 |
| 최종 암호 | 숫자 칸 5개와 둥근 큰 자판 | 암호가 맞음 |

## 7. E3 일시정지

플레이 화면 위를 어둡게 덮고 가운데에 흰 카드(주황 테두리): 주황 캐릭터, "잠깐 멈췄어요!", 이유 알약(예: 뒷좌석 오른쪽 문이 열렸어요), "문을 닫으면 저절로 이어서 놀 수 있어요.", 게임 끝내기 버튼. 주행 전환이면 빨간 테두리와 "홈으로" 버튼.

## 8. E4 탈출 성공

- 헤더: 별 6개 모두 채움, 상태 알약 "설정 돌려놓는 중".
- 왼쪽 큰 카드(연한 주황): 색종이, 열린 글로브박스와 선물, "철컥!", "글로브박스가 열렸어요. 보물을 꺼내요!"
- 오른쪽: 기록 카드(제목, 걸린 시간, 힌트 수, 암호), 원상 복구 카드(문 잠금, 창문 잠금, 공조, 조명, 시트 통풍과 열선, 스마트 글래스, 하이패스 안내음), 버튼 "새 이야기로 또 하기", "홈으로".

## 9. E5 설정 (보호자용)

| 항목 | 종류 |
|---|---|
| AI 게임마스터 | 칩: 차량 LLM (Pleos), 내장 생성기 |
| 장소 힌트 | 칩: 자동 (위치), 바다, 산, 도심, 휴게소, 충전소 |
| 데모 모드 (가짜 차량) | 스위치 |
| 안전 확인 수동 통과 | 스위치 |
| 시연 도구 보이기 | 스위치 |

오른쪽 카드에 차량 기록(보낸 명령과 받은 신호).

## 10. E6 NPC 대화

오른쪽에서 열리는 흰 패널(폭 700): 캐릭터와 이름, 닫기, 말풍선 목록(내 말은 파란 말풍선 오른쪽, NPC는 테마 연한 색 말풍선 왼쪽에 말한 사람 이름), "듣고 있어요" 표시, 큰 말하기 버튼.

## 11. 시연 도구 (설정에서 켬)

안전 확인과 플레이 화면 맨 아래에 작은 칩 줄: 성애 제거, 내기 순환, 공기청정, 독서등(아이 좌석), 핸들 -90/-45/0/+45/+90, 브레이크, 왼쪽과 오른쪽 깜빡이, 온도 -0.5/+0.5, 문, 벨트, 기어. 에뮬레이터 Virtual Console에 없는 장치도 같은 신호를 넣을 수 있습니다.
