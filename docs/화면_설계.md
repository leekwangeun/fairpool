# 화면 설계 (차량 화면)

차량탈출 : AI 멀티버스의 차 앱 화면입니다. 피그마 시안과 Compose 코드가 모두 이 문서를 따릅니다.

## 1. 공통

| 항목 | 값 |
|---|---|
| 화면 크기 | 가로 1682 x 1210 (Pleos Connect 에뮬레이터 단독 실행 기준) |
| 바깥 여백 | 48 |
| 카드 모서리 | 28 (큰 카드), 20 (작은 카드), 16 (칩과 버튼) |
| 글꼴 | Pretendard (없으면 시스템 sans). 제목 44 Bold, 큰 본문 30 SemiBold, 본문 26 Medium, 보조 22 Regular, 칩 20 Medium |
| 버튼 | 높이 96, 글자 30 SemiBold. 주 버튼은 채움, 보조 버튼은 테두리 |
| 상단 바 | 높이 112. 왼쪽 앱 이름, 가운데 차량 상황 칩, 오른쪽 설정 또는 비상 해제 버튼 |

### 색

어두운 차 안에서 보는 앱이라 어두운 바탕을 기본으로 합니다.

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| bg | #0B1020 | 화면 바탕 |
| surface | #151B2E | 상단 바, 패널 |
| card | #1C2440 | 카드 |
| cardSoft | #242D4F | 카드 안의 칸, 칩 |
| line | #2F3A61 | 테두리, 구분선 |
| text | #F2F4FF | 본문 |
| sub | #9AA3C0 | 보조 글자 |
| primary | #5B7CFF | 주 버튼, 진행 표시 |
| success | #2ED47A | 통과, 잠금 확인 |
| warn | #FFB020 | 주의 |
| danger | #FF4D4F | 비상 해제, 일시정지 |

테마마다 강조색이 있고, 플레이 화면의 앰비언트 띠와 카드 테두리, 홈의 테마 카드 배경에 씁니다.

| 테마 | 강조색 | 배경 그라데이션 |
|---|---|---|
| 1 보물 잠수함 (키즈 어드벤처) | #27C7D9 | #0E4A6B → #062B45 |
| 2 코드 레드 (키즈 SF) | #FF5A3C | #4A1C12 → #2A0C08 |
| 3 고스트 택시 (4D 호러) | #1FD1B0 (유령) 과 #B3122E (핏빛) | #1B0A1E → #080308 |
| 4 밀실의 탐정 (추리) | #E6B452 | #3B2E12 → #1C1608 |

### 차량 상황 칩

상단 바 가운데에 4개를 나란히 둡니다. 아이콘 없이 글자로만 적습니다.

| 칩 | 예 |
|---|---|
| 장소 | 바다 근처 휴게소 |
| 날씨 | 비 (와이퍼 작동) 또는 맑음 |
| 배터리 | 45% 충전 중 |
| 시간 | 밤 21:40 |

## 2. 화면 목록

| 번호 | 이름 | 언제 |
|---|---|---|
| E0 | 홈 (테마 고르기) | 앱을 켜면 |
| E1 | 안전 확인 (Safety Sandbox) | 테마를 고르면 |
| E2 | 플레이 | 안전 확인을 모두 통과하고 시작을 누르면. 단계마다 가운데 기믹 그림이 바뀜 |
| E3 | 일시정지 | 문 열림, 안전벨트 풀림, 주행 전환 |
| E4 | 탈출 성공 | 마지막 암호를 맞히면 |
| E5 | 설정 | 상단 바 설정 버튼 |
| E6 | NPC 대화 | 플레이 화면에서 말하기 버튼 |

## 3. E0 홈 (테마 고르기)

```
┌──────────────────────────────────────────────────────────────────┐
│ 차량탈출 : AI 멀티버스     [바다 근처 휴게소][비][45% 충전 중][밤 21:40]  [설정] │
├──────────────────────────────────────────────────────────────────┤
│ 오늘의 방탈출을 고르세요                                            │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐              │
│ │ 테마 1    │ │ 테마 2    │ │ 테마 3    │ │ 테마 4    │   (각 370x560) │
│ │ 보물 잠수함│ │ 코드 레드 │ │ 고스트 택시│ │ 밀실의 탐정│              │
│ │ 키즈 어드벤처│ 키즈 SF  │ │ 4D 호러   │ │ 추리      │              │
│ │ 권장 5~10세│ │ 충전 중 추천│ 비 오는 밤 해금│ 온 가족  │              │
│ │ [고르기]   │ │ [고르기]   │ │ [고르기]   │ │ [고르기]   │              │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘              │
│ ┌───────────────────────────┐ ┌────────────────────────────────┐ │
│ │ 보물 넣기                   │ │ 크루                           │ │
│ │ 글로브박스에 간식이나 선물을  │ │ 1열 기관장: 운전석 (부모)        │ │
│ │ 넣고 닫아 주세요. 시작하면   │ │ 2열 탐정: [조수석][뒷좌석 왼쪽]  │ │
│ │ 잠깁니다.                   │ │            [뒷좌석 오른쪽]       │ │
│ └───────────────────────────┘ └────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

- 테마 카드는 테마 배경 그라데이션 위에 흰 글자. 카드 위쪽에 큰 테마 번호, 아래쪽에 이름, 부제, 권장 대상, 추천 상황 칩.
- 추천 상황 칩은 차량 상황과 맞을 때 강조색으로 채웁니다(충전 중이면 테마 2, 비 오는 밤이면 테마 3).
- 아이 좌석은 좌석 센서가 켜진 자리를 먼저 골라 둡니다. 부모가 바꿀 수 있습니다.

## 4. E1 안전 확인 (Safety Sandbox)

```
┌──────────────────────────────────────────────────────────────────┐
│ ← 돌아가기        테마 1 보물 잠수함        안전 확인                │
├──────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────┐ ┌─────────────────────────────┐ │
│ │ 출발 전 확인 (6)              │ │ AI 게임마스터                 │ │
│ │ ● 기어 P                 통과 │ │ 오늘의 에피소드를 만드는 중...  │ │
│ │ ● 운전석과 아이 좌석 착석  통과 │ │ 장소: 바다 근처 휴게소          │ │
│ │ ● 안전벨트 (아이)         통과 │ │ 날씨: 비                     │ │
│ │ ● 문 잠금               잠그는 중│ │ 배터리: 45%                  │ │
│ │ ● 창문 닫힘과 잠금        통과 │ │ ─────────────────────────   │ │
│ │ ● 글로브박스 잠금         통과 │ │ 차량 설정 백업 완료            │ │
│ │                              │ │ (공조, 조명, 창문, 글로브박스)   │ │
│ └──────────────────────────────┘ └─────────────────────────────┘ │
│                                        [ 방탈출 시작 ]            │
└──────────────────────────────────────────────────────────────────┘
```

- 항목은 통과(초록 점), 진행 중(파랑 점, 회전), 실패(빨강 점, 이유)의 세 상태입니다.
- 차가 지원하지 않는 항목(예: 에뮬레이터의 글로브박스)은 "확인 불가, 건너뜀"으로 회색 표시하고 통과로 칩니다.
- 모든 항목이 통과하고 에피소드가 만들어지면 "방탈출 시작"이 켜집니다.

## 5. E2 플레이

세 칸으로 나눕니다. 왼쪽 이야기 460, 가운데 기믹 그림 나머지, 오른쪽 크루 400.

```
┌──────────────────────────────────────────────────────────────────┐
│ 보물 잠수함  단계 3 / 6   ████████░░░░   경과 06:12      [비상 전체 해제] │
├──────────────┬────────────────────────────────┬──────────────────┤
│ (NPC 얼굴)    │                                │ 1열 기관장 (부모)  │
│ 잠수함 AI 노틸│    기믹 그림 (단계마다 바뀜)      │ 성애 제거 버튼을   │
│              │                                │ 켜서 김을 걷어내세요│
│ "앞 유리에 김 │                                │                  │
│ 이 서렸어. 걷 │                                │ 2열 탐정 (아이)    │
│ 어내면 해류   │                                │ 창에 나타나는 숫자를│
│ 암호가 보여!" │                                │ 읽어 주세요        │
│              │                                │                  │
│ 지난 단서     │                                │ [ 말하기 ]        │
│ 4 _ _ _      │                                │ [ 힌트 ]          │
├──────────────┴────────────────────────────────┴──────────────────┤
│ 4D 연출: 앰비언트 푸른색  통풍 꺼짐  독서등 2열 오른쪽 켜짐              │
└──────────────────────────────────────────────────────────────────┘
```

### 기믹 그림 (가운데)

| 단계 | 그림 | 통과 조건 |
|---|---|---|
| 성애 제거 | 뿌연 앞 유리. 숫자가 김 뒤에 희미하게. 성애 제거가 켜지면 김이 걷히고 숫자가 또렷해짐 | 앞 유리 성애 제거, 최대 성애 제거, 사이드미러 열선 중 하나 켜짐 |
| 빛의 조각 | 차를 위에서 본 그림, 창문 4개. 한 창만 밝음. 부모가 창을 누르거나 아이가 말로 답함 | 밝은 창의 위치를 맞힘 |
| 공기 정화 | 독가스 게이지가 차오름. 내기 순환과 공기청정 두 스위치 표시 | 내기 순환 켜짐 그리고 공기청정 켜짐 |
| 손전등 신호 | 아이 좌석의 독서등 그림. "3번 깜빡" 목표와 지금까지 켠 횟수 | 독서등이 목표 횟수만큼 켜짐 |
| 금고 다이얼 | 핸들 각도 게이지(목표 각도 표시), 브레이크 표시, 깜빡이 횟수 | 목표 각도 안에서 브레이크, 그 뒤 깜빡이 목표 횟수 |
| 온도 암호 | 온도 게이지와 목표 온도 | 공조 설정 온도가 목표와 같음 |
| 최종 암호 | 지금까지 모은 숫자 칸과 자판. 말하기로도 가능 | 암호가 맞음 |

- 통과하면 가운데 그림 위에 큰 "통과" 표시가 1.5초 보이고 다음 단계로 넘어갑니다.
- 오른쪽 역할 카드는 부모와 아이가 할 일을 짧은 문장으로 나눠 적습니다. 아이가 운전석 장치를 만지지 않게 역할을 고정합니다.

## 6. E3 일시정지 (오버레이)

플레이 화면 위를 반투명 검정(80%)으로 덮고 가운데 카드를 둡니다.

- 큰 글자: "잠깐 멈췄어요"
- 이유: "뒷좌석 오른쪽 문이 열렸어요" 또는 "아이 안전벨트를 매 주세요" 또는 "차가 움직여요. 게임을 끝내고 설정을 돌려놓았어요"
- 안내: "해결되면 자동으로 이어집니다"
- 버튼: 게임 종료 (보조)

## 7. E4 탈출 성공

- 가운데 큰 글로브박스 그림이 열리는 애니메이션과 "철컥!" 글자.
- 에피소드 제목, 걸린 시간, 쓴 힌트 수.
- "차량 설정 원상 복구" 목록: 문 잠금, 창문 잠금, 공조, 조명, 스마트 글래스. 각각 통과 표시.
- 버튼: 다시 하기 (다른 에피소드), 홈으로.

## 8. E5 설정

| 항목 | 종류 |
|---|---|
| AI 게임마스터 | 선택: 차량 LLM (Pleos LLM SDK), 내장 생성기 |
| 장소 힌트 | 선택: 자동(위치), 바다, 산, 도심, 휴게소, 충전소 |
| 데모 모드 (가짜 차량) | 스위치. 켜면 차량 SDK 대신 앱 안의 가짜 차가 응답 |
| 안전 확인 수동 통과 | 스위치. 에뮬레이터에서 확인할 수 없는 항목을 통과로 침 |
| 시연 도구 보이기 | 스위치. 플레이 화면 아래에 신호 버튼 줄이 생김 |

## 9. E6 NPC 대화 (오버레이)

- 오른쪽에서 열리는 패널(폭 640). 위에 NPC 이름과 역할, 가운데 대화 목록(나는 오른쪽 파란 말풍선, NPC는 왼쪽 카드색 말풍선), 아래에 "듣는 중" 표시와 자판 입력 칸.
- 말하기 버튼을 누르면 차량 마이크로 듣고, 끝나면 NPC가 음성으로 답합니다.

## 10. 시연 도구 (설정에서 켬)

플레이 화면 맨 아래에 작은 버튼 줄: 성애 제거, 내기 순환, 공기청정, 독서등(아이 좌석), 핸들 -90, 핸들 0, 브레이크, 왼쪽 깜빡이, 온도 18.5, 문 열림, 문 닫힘, 벨트 풀기, 벨트 매기. 실제 차 신호 위에 덧씌워서 에뮬레이터의 Virtual Console에 없는 장치도 흐름을 보여 줄 수 있습니다.
