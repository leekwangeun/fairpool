# 차량탈출 : AI 멀티버스 (Car Escape : AI Multiverse)

차량 상황에 맞춰 AI가 만든 이야기와 차량의 실제 장치로 푸는 퍼즐로, 잠긴 글로브박스 속 보물을 여는 Pleos Connect 차량용 협동 방탈출 앱입니다.

## 앱 소개

- **정차 중 아이 안전부터 잠급니다.** 시작하면 문, 창문, 글로브박스를 잠그고, 문 열림, 안전벨트 풀림, 주행 전환을 계속 감시합니다. 문이 열리거나 벨트가 풀리면 바로 멈추고, 차가 움직이면 게임을 끝내고 차량 설정을 원래대로 돌려놓습니다.
- **AI 게임마스터가 매번 새 에피소드를 씁니다.** 현재 위치(바다, 산, 도심, 휴게소), 날씨(와이퍼), 배터리, 시간을 넣어 차량 LLM(Pleos LLM SDK)이 이야기와 대사를 쓰고, 앱이 퍼즐 값을 차가 낼 수 있는 범위로 검사합니다. LLM이 없으면 내장 생성기가 대신합니다.
- **차량 장치가 곧 퍼즐입니다.** 성애 제거, 스마트 글래스, 내기 순환과 공기청정, 독서등, 핸들과 브레이크와 깜빡이, 공조 온도가 각각 하나의 기믹입니다.
- **보호자와 아이가 역할을 나눕니다.** 운전석 보호자(1열 기관장)는 차량 장치를, 아이(2열 탐정)는 단서 읽기와 독서등과 말하기를 맡습니다. 아이는 운전석 장치를 만지지 않습니다.
- **마지막 암호를 맞히면 글로브박스가 열립니다.** 미리 넣어 둔 간식이나 선물이 진짜 보상이 되고, 게임 전에 백업한 차량 설정을 그대로 돌려놓습니다.

## 저장소 구성

| 폴더 | 내용 |
|---|---|
| `apk/` | 제출용 release APK (`CarEscape_차량탈출_release.apk`) |
| `car/` | 차량 앱 (Kotlin, Jetpack Compose, Pleos Connect SDK) |
| `car/app/src/test/` | 퍼즐 판정, 안전 규칙, 에피소드 생성, LLM 응답 처리 단위 테스트 23개 |
| `car/scripts/` | 에뮬레이터 Virtual Console로 시연 시작 상태를 만드는 스크립트 |
| `docs/` | 화면 설계, 차량 SDK 연동 |

## 실행 방법

### 1. APK 설치

1. Pleos Connect 에뮬레이터(또는 차량)를 켭니다.
2. APK를 설치하고 실행합니다.

```bash
adb install -r apk/CarEscape_차량탈출_release.apk
```

```bash
adb shell am start --user 10 -n kr.carescape.multiverse/.MainActivity
```

### 2. 시연 시작 상태 만들기 (선택)

Virtual Console로 주차, 뒷좌석 오른쪽 착석, 문 닫힘을 맞추고 앱을 띄웁니다. `drive` 를 붙이면 플레이 중에 문 열림과 주행 전환으로 안전 가드를 보여 줍니다.

```bash
bash car/scripts/demo_setup.sh drive
```

### 3. 소스에서 빌드

JDK 17 이상, Android SDK 35, Gradle 8.10 이상이 필요합니다. `car/` 폴더를 Android Studio로 열거나 아래처럼 빌드합니다.

```bash
gradle -p car assembleRelease
```

```bash
gradle -p car testReleaseUnitTest
```

## 시연 순서

| 순서 | 화면 | 하는 일 |
|---|---|---|
| 1 | E0 홈 | 차량 상황 칩(장소, 날씨, 배터리, 시간)을 보고 추천 테마를 고름. 아이 좌석을 고름 |
| 2 | E1 안전 확인 | 기어 P, 착석, 아이 안전벨트, 문, 창문, 글로브박스 잠금이 차례로 통과. 그동안 AI가 에피소드를 씀 |
| 3 | E2 플레이 | 기믹 5개를 풀 때마다 단서 숫자가 하나씩 모임. 말하기 버튼으로 NPC에게 묻거나 힌트를 받음 |
| 4 | E3 일시정지 | 문을 열거나 벨트를 풀면 멈추고, 해결하면 이어짐. 기어를 D로 바꾸면 게임 종료와 원상 복구 |
| 5 | E4 탈출 성공 | 최종 암호를 말하거나 입력하면 글로브박스가 열리고, 차량 설정 복구 목록이 표시됨 |

에뮬레이터에 없는 장치(스마트 글래스, 독서등, 핸들 등)는 설정의 **시연 도구 보이기**를 켜면 화면 아래 버튼으로 같은 신호를 넣을 수 있습니다. 확인할 수 없는 잠금 항목은 **안전 확인 수동 통과**를 켜야 넘어갑니다. 차량 없이 흐름만 보려면 **데모 모드**를 켭니다.

## 테마와 기믹

| 테마 | 대상 | 기믹 순서 (마지막은 최종 암호) |
|---|---|---|
| 1 보물 잠수함 | 5~10세 가족, 바다와 휴게소 | 손전등 신호, 성애 제거, 빛의 조각, 금고 다이얼, 공기 정화 |
| 2 코드 레드 | 키즈와 주니어, EV 충전 대기 | 공기 정화, 성애 제거, 온도 암호, 금고 다이얼, 손전등 신호 |
| 3 고스트 택시 | 초등 고학년, 커플, 친구, 비 오는 밤 | 손전등 신호, 성애 제거, 온도 암호, 금고 다이얼, 빛의 조각 |
| 4 밀실의 탐정 | 온 가족, 성인 커플 | 빛의 조각, 온도 암호, 금고 다이얼, 성애 제거, 손전등 신호 |

| 기믹 | 차량 신호 | 통과 조건 |
|---|---|---|
| 성애 제거 | 앞 유리 성애 제거, 최대 성애 제거, 사이드미러 열선 | 하나라도 켜짐 |
| 빛의 조각 | 스마트 글래스 존 제어로 한 창문만 투명 | 아이가 말한 창문을 보호자가 화면에서 누름(또는 말하기) |
| 공기 정화 | 내기 순환, 공기청정 | 둘 다 켜짐 |
| 손전등 신호 | 아이 좌석 독서등 | 꺼짐에서 켜짐으로 목표 횟수 |
| 금고 다이얼 | 핸들 각도, 브레이크, 방향지시등 | 목표 각도 ±12도에서 브레이크, 그 뒤 정해진 쪽 깜빡이 목표 횟수 |
| 온도 암호 | 공조 설정 온도 | 목표 온도 ±0.25도 |
| 최종 암호 | 음성 인식 또는 화면 자판 | 모은 숫자 다섯 개 |

## 테스트 환경과 필요한 설정

| 항목 | 내용 |
|---|---|
| 차량 | Pleos Connect 에뮬레이터 (Android Automotive), 가로 화면 |
| SDK | Vehicle 2.3.2, LLM 2.1.3.2, TextToSpeech 3.3.1, SpeechToText 3.3.1, FusedLocation 1.1.3 (Pleos Maven 저장소) |
| 서버 | 없음. 외부 생성형 AI API 키도 쓰지 않음 |
| 권한 | 실행 중 허용: 마이크(`RECORD_AUDIO`), 위치(`pleos.car.permission.FUSED_LOCATION`) |

| 설정 (앱의 E5 화면) | 기본값 | 내용 |
|---|---|---|
| AI 게임마스터 | 차량 LLM | 차량 LLM이 없거나 답이 늦으면(에피소드 25초, 대답 12초) 내장 생성기로 바뀜 |
| 장소 힌트 | 자동 | 위치로 판별. 바다, 산, 도심, 휴게소, 충전소로 고정 가능 |
| 데모 모드 | 꺼짐 | 차량 SDK 대신 앱 안의 가짜 차 |
| 안전 확인 수동 통과 | 꺼짐 | 차가 답하지 않는 항목을 건너뜀으로 표시 |
| 시연 도구 보이기 | 꺼짐 | 안전 확인과 플레이 화면 아래 신호 버튼 줄 |

## 안전 설계

- 게임은 기어 P, 차속 3km/h 이하에서만 시작하고 진행합니다. 둘 중 하나라도 벗어나면 즉시 게임을 끝내고 원상 복구합니다.
- 끼임이 생길 수 있는 모터(시트 이동, 창문 오르내림)는 퍼즐에 쓰지 않습니다. 창문은 시작할 때 닫고 잠그기만 합니다.
- 바꾸기 전에 문 잠금, 창문 잠금, 글로브박스, 독서등, 실내등, 앰비언트, 시트 통풍과 열선, 공조, 스마트 글래스, 하이패스 안내음을 백업합니다. 백업은 기기에 저장해 두므로, 앱이 비정상 종료돼도 다음 실행 때 자동으로 돌려놓습니다.
- 모든 화면 위쪽의 **비상 전체 해제**는 게임을 멈추고, 설정을 돌려놓고, 문과 창문과 글로브박스 잠금을 모두 풉니다.

자세한 SDK 호출은 [docs/차량_SDK_연동.md](docs/차량_SDK_연동.md), 화면 구성은 [docs/화면_설계.md](docs/화면_설계.md)에 있습니다.
